# 设计原则

> 赛博朋克 · 数字穿越 · 未来科技。这句话决定了下面每一条规则。

## 先排除什么

赛博朋克最容易翻车的两种方式：**紫蓝渐变的糊汤**，和**霓虹弹球机**。
这套库用六条硬规则避开它们。

| 常见赛博朋克翻车 | 这里的做法 | 为什么 |
| --- | --- | --- |
| 满屏霓虹发光 | 近黑底 + 一处霓虹 | 霓虹只在暗处才亮；处处发光等于没有光 |
| 紫蓝渐变铺满 | 单一电光青 + 品红信号 | 渐变是最像"AI 生成"的视觉签名 |
| 圆角玻璃卡片 | 零圆角 + 1px 发丝线 | 玻璃圆角是 SaaS 后台的制服 |
| 多个"强调色"抢戏 | 青=行动，品红=信号 | 强调色出现八次就等于没强调 |
| 弹跳/回弹动画 | 机械短促（120–420ms） | 未来感来自精确，不来自弹性 |
| 装饰性发光边框 | 辉光只表达层级与聚焦 | 光要有语义，否则是噪音 |

## 六条原则

### 1. 深空底，霓虹只在暗处亮

背景 `--myui-color-bg: #05070d`——近黑、微蓝、几乎中性。
所有明亮的东西都靠这块安静的地面衬出来。加一层 24px 数据网格
（`--myui-color-grid`，5.5% 透明度），宇宙才有坐标系。

### 2. 一个行动色

`--myui-color-accent: #19e0ff`（电光青）只出现在"现在该点这里"。
品红 `--myui-color-signal: #ff2e88` 是**信号**：新东西、告警、热标记。
它不是第二个按钮色，更不是装饰。

霓虹文字只在**大字或粗体**上使用；正文一律回到三级冰白。

### 3. 发丝线，不是墨线

结构线一律 1px（`--myui-border-width`），颜色是冷蓝灰 `#1b2a3d`，
可交互边线用 `--myui-color-line-strong`（38% 透明青）。
1px 读起来像电路，2px 读起来像印刷海报——我们要前者。

### 4. 辉光即层级

没有投影，只有光：`--myui-shadow-glow-sm/-glow/-glow-lg`，
范围 8–40px、低透明度。按钮悬停时**变亮并上浮 1px**，按下时光熄灭——
像按下一个控制台按键。面板用 `--myui-shadow-inset` 做一层内描边，
模拟屏幕边缘。

### 5. 排版就是 HUD

显示体 **Chakra Petch**（几何、切口、技术感），正文 **Inter**，
微标签一律等宽字体 + 大写 + `0.16em` 字距——这是仪表盘的语气。
字号七级（12/13/15/19/24/32/44），不发明中间值。
中文标题回落到 PingFang SC / 微软雅黑，行高不低于 1.04（中文字面撑满 em 框）。

### 6. 动效机械、可关闭

`120–420ms`，缓动 `cubic-bezier(.2,.9,.25,1)`，只表达状态变化。
全部动画在 `prefers-reduced-motion` 下退化为静态——赛博朋克不等于
对前庭功能不友好的闪烁。

## 特效组件的态度

`Magic` 与 `Flotage` 是**包裹型**组件：不生产内容，只给已有内容加一层情绪。
这是"数字穿越"的具象化——信号穿过界面。

1. 不改变布局盒子尺寸策略（`inline-block` 包裹，内容自己决定宽高）；
2. 关闭后与普通容器无异（`disabled` 不残留滤镜）；
3. 尊重 `prefers-reduced-motion`，退化为静态；
4. 不劫持内部交互（点击、焦点、键盘照常穿透）。

```vue
<MyuiMagic mode="glitch" :intensity="0.6">
  <MyuiButton size="lg">接入中继站</MyuiButton>
</MyuiMagic>
```

## 命名与结构约定

- 组件前缀 `Myui`，CSS 前缀 `.myui-`，模板标签 `<myui-button>`。
- 修饰符 `--`，内部元素 `__`，状态用 data 属性。
- 组件样式不使用 `scoped`：命名空间已经保证不泄漏，`scoped` 只会让覆盖变难。
- 样式只允许引用令牌，不允许出现字面量颜色/间距/圆角。

## 自查清单

发布前过一遍：

- [ ] 背景是否近黑且近乎中性？有没有出现第三种霓虹色？
- [ ] 强调色（青）是否只用于可操作/当前状态？
- [ ] 结构线是否都是 1px？圆角是否只有 `0` 和 `999px`？
- [ ] 辉光是否只在层级/聚焦处出现，且范围不超过 40px？
- [ ] 键盘 Tab 一圈，焦点是否始终可见（2px 青色环 + 辉光）？
- [ ] 打开"减弱动态效果"，是否所有动画停止？
- [ ] 空状态、加载中、错误态是否都有样子？
- [ ] 把标题换成三倍长度，布局是否还成立？
